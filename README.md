# 🍽️ Meal Magic

A food ordering web application built with Angular 16 and Node.js.

## Prerequisites

- Node.js (v16+)
- npm

## Quick Start

### Backend

```bash
cd backend
npm install
npm start
```

Runs on `http://localhost:3000`

### Frontend

```bash
npm install
npm start
```

Runs on `http://localhost:4200`

## Features

- 🔐 User authentication (login/signup)
- 🍕 Browse & order dishes
- 🛒 Cart & checkout
- ⭐ Reviews & ratings
- 📊 Admin dashboard

## Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Start dev server |
| `npm run build` | Production build |
| `npm test` | Run unit tests |

## Tech Stack

- **Frontend:** Angular 16, Angular Material
- **Backend:** Node.js, Express
- **UI:** ngx-toastr for notifications
